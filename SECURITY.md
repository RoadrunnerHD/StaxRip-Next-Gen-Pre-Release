# Security Policy

## Supported versions

Security fixes target the latest StaxRip Next Gen pre-release and the current main branch. Older packages should be updated before reproducing an issue.

## Reporting a vulnerability

Do not publish exploit details, credentials, private files or unredacted logs in public issues.

When GitHub private vulnerability reporting is available, use **Security → Advisories → Report a vulnerability** in this repository.

If that option is unavailable, open an issue containing only a request for a private reporting channel. Do not include the vulnerability details or affected private data. The maintainer can then arrange a private channel before receiving the report.

In a private report, include the application version, affected component, reproduction steps, impact and a minimal example. Remove passwords, tokens and personal information from any logs.

## Scope

Include the name and version of any affected bundled tool. Third-party components are also maintained by their respective upstream projects. Project files and AviSynth, VapourSynth or PowerShell scripts can contain executable instructions; only run scripts and projects from sources you trust.
