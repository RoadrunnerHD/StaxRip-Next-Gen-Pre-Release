# [Documentation](../README.md) / [Introduction](README.md) / Installation

StaxRip Next Gen Pre-Release 2 is portable and has no installer.

1. Download `StaxRip-Pre-Release-2.7z` from the GitHub release assets.
2. Extract the complete archive using 7-Zip into a folder where your Windows account has write permission.
3. Keep `Apps`, `Fonts`, `Icons` and `Runtime` beside `StaxRipNG.exe`.
4. Start `StaxRipNG.exe` from the extracted main folder.

The package includes .NET 10, AviSynth+, VapourSynth and Python. These do not need to be installed separately for the portable package. Some tools may require Visual C++ runtime libraries.

The source ZIP is intended for building the application and does not replace the portable program download.

Continue with [First Start](../Usage/First-Start.md). See [System Requirements](System-Requirements.md) for hardware and operating-system requirements.
